# History

This directory archives completed or deprecated historical documents, records, and task lists from past implementation cycles.

## Rules
- Content in `history/` is archival only.
- It is NOT the source of truth for current architecture, requirements, implementation status, or future stages.
- Coding agents must NOT read or use files under `history/` as project instructions unless the current task explicitly requests historical context.
- Current active specifications and status must be derived from `AGENTS.md`, `DEVELOPMENT_WORKFLOW.md`, `IMPLEMENTATION_STATUS.md`, and the formal specifications under `docs/`.
